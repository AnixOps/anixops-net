# AnixOps Net v0.3.0-beta.8

这一版的重点是：苹果平台多了系统代理接管方式，DNS 支持 UDP / DoQ / 系统 DNS 与多上游竞速，策略组出错会自己换节点，规则多了 REJECT 变体和按来源地址、监听端口分流；另外排查了所有平台的界面入口，连接开关和失败原因在每一页都能看到。

## 升级前请先看

- **iOS / macOS 默认接管方式改为“VPN + 系统代理”。** 隧道照常接管全部流量，同时把系统 HTTP / HTTPS 代理指向本机，浏览器的请求按域名分流，明文 HTTP 的 URL 规则也能生效。想回到原来的方式，在设置里把接管方式改成“仅 VPN”。
- **安卓新装用户首次启动会选择使用方式（代理 / 调试网络）。** 已经有订阅或节点的用户升级后不会被询问，仍是代理模式。

## 新功能

### 接管方式与网关（iOS / macOS）

- 接管方式可选“VPN + 系统代理”（默认）、“仅 VPN”；macOS 还可以选“仅系统代理”，不建默认路由。可以编辑“跳过代理的地址”。
- macOS 网关模式：局域网设备把路由器设为这台 Mac、DNS 设为 `198.18.0.2`，流量经 Mac 进隧道。只支持 IPv4，单个 WireGuard 节点不支持。系统不允许打开转发时，设置页会给出可以复制的命令。

### DNS（所有平台）

- 服务器可以写 `udp://`、`quic://`（DoQ）和 `system`（物理网络的系统 DNS）。
- 最多 4 个“默认”服务器同时查询，取最先回来的应答；可以设一个“备用”服务器。
- Fake-IP 支持 IPv6 范围。

### 策略组

- 自动测速、故障转移、负载均衡组里的节点建立连接失败时，立即只重测这个节点；重测失败就换节点，不再等下一轮测速。
- 切换网络后清空测速结果，下一条连接到来时重新测。
- url-test 组的容差真正生效：当前节点比最快的慢得不多就不换。
- 新的“按网络选择”组：按路由器、子网、网络类型（Wi-Fi / 有线 / 蜂窝）选择不同的节点或组，可以从 Surge 的 `subnet` 组导入。Windows、安卓允许位置权限后还能按 Wi-Fi 名称选择；iOS / macOS 暂时读不到 Wi-Fi 名称，只能用路由器、子网和网络类型。

### 规则与分流

- “我的规则”支持 `REJECT-NO-DROP`、`REJECT-DROP`、`REJECT-TINYGIF`（`REJECT-IMG` 同 `REJECT-TINYGIF`）。同一主机 30 秒内被拒绝超过 10 次后自动改为静默丢弃，避免 App 疯狂重试。
- “我的规则”支持 `SRC-IP`（`SRC-IP-CIDR`）和 `IN-PORT`，按发起连接的设备地址、连上的本地端口分流，例如给局域网里的某台设备单独走一个节点。
- Windows、Linux、安卓的“我的规则”可以通过链接添加规则集，也能写 `GEOIP,CN` / `GEOSITE,cn`（与 iOS / macOS 相同，内置的只有这两份中国列表）。
- 开启 HTTPS 解密并且规则里有 `URL-REGEX` 或 `USER-AGENT` 时，解密后的每个请求按自己的地址重新分流，不再整条连接只走一个出口。

### 连接与性能

- FTP、SMTP、POP3、IMAP、MySQL、VNC 这类服务器先发言的协议不再等 App 先发数据，连接更快；其他从不先发数据的地址会被记住 30 分钟。
- macOS、Windows、Linux 的隧道改为多线程（每个 CPU 一个线程，最多 4 个），多核机器上能用上更多 CPU。

## 界面

- iOS 调试模式每个标签底部加了连接条，可以直接连接或断开隧道（以前调试模式里找不到开关）。
- 所有平台：连接失败、模式切换失败等提示在当前页面就能看到，不必回到首页。
- 安卓调试模式每页底部常驻连接条；没有节点时首页给出“导入订阅”按钮，并写明原因。
- iOS / macOS 调试模式在设置页加了流量统计入口；macOS 菜单栏在调试模式显示出口和失败原因。

## 修复

- iOS / macOS ANX 版：机场开启设备授权后 ANX 节点反复断开（诊断里是 `code 6`）。
