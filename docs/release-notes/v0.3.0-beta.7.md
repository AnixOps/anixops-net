# AnixOps Net v0.3.0-beta.7

这一版距离 beta.6 合并了 110 个客户端改动和 23 个内核改动。重点是：安卓换成原生界面，桌面和安卓补齐了 iOS 已有的大部分功能，调试模式（抓包、解密、重放、映射）在所有平台上可用，公开版不再带任何预设分流规则和脚本。

## 升级前请先看

- **不再内置分流预设和去广告插件。** “绕过大陆”“GFW 列表”“回国”模式、推荐规则库、内置去广告和哔哩哔哩插件都去掉了。升级后，原来选这些模式的会变成“规则”模式：只按订阅自带的规则和你自己的规则分流，其余走代理。需要分流的，请用订阅自带的规则，或在规则页“通过链接添加规则集”。
- **DNS“国内外分流”选项去掉了。** 原来选它的，第一次启动时会转成内容相同的“自定义 DNS”，可以自己修改或删除。
- **HTTPS 解密的根证书改为手动信任。** 开启解密时客户端不再自动把根证书装进系统信任库，会打开证书窗口让你自己确认；关闭解密时保留证书，再开启不用重新信任。旧版本自动装入的证书会被清理。
- **Windows 去掉了“服务模式”。** 内核只在窗口进程里运行，关闭窗口会断开连接。旧版本注册的 Windows 服务会在首次启动时自动卸载。
- **安卓**：这是第一个放在 Release 里的安卓版。

## 新功能

### 安卓（全新原生界面）

- 用 Jetpack Compose 重写，首页、代理、规则、扩展、调试、设置都是原生页面，跟随系统深浅色。
- 扫码导入订阅、分享节点链接，支持 `anixops://` 链接。
- 快捷设置磁贴一键连接，支持系统“始终开启的 VPN”。
- 调试：请求列表与详情、HTTPS 解密检查清单、单条重放、抓包会话和导出、Map Local / Remote、流量重定向、连接视图。
- 日志查看和按天流量统计；诊断报告存到“下载”。

### Windows / Linux（桌面）

- 代理 / 调试两种使用方式，调试模式可设直连出口。
- 请求列表：快捷筛选和表达式搜索；检查器可停靠在右侧或下方，显示进行中的请求、SSE 事件、WebSocket 消息和 HTTP/2 帧，正文自动解压。
- 单条请求重放与编辑后重放，Map Local / Remote 可视化，流量重定向。
- 抓包查看与导出（pcapng / HAR），抓包会话加密保存、载入回看，7 天后自动清理。
- 手机连电脑抓包：电脑共享代理，手机按页面指引安装证书。
- 我的规则、自定义 DNS / Hosts、Fake-IP。
- 节点分享、编辑和删除；插件从文件或粘贴导入，可查看插件内容。
- 日志查看（按级别、模块、文字筛选），按天流量统计，系统通知（脚本通知、意外断开、订阅更新失败）。
- 按 Wi-Fi 自动连接 / 断开（Windows），支持 `anixops://` 链接。
- **Linux 新增 TUN 模式**（通过 polkit 提权）。
- Windows 11 使用 Mica 背景；下拉、菜单、对话框统一改版，界面改用系统字体。
- 粘贴多条链接时保持为一个订阅；订阅更新失败时写明原因和错误代码。

### iOS / macOS（TestFlight / 面板下载）

- 代理 / 调试双模式，首次启动选择。
- 请求检查器：标签页和结构化正文（JSON 树、格式化、图片、表单、十六进制、时间线），显示进行中的请求、事件 / WebSocket 消息和 HTTP/2 帧。
- 请求详情导出（cURL、代码、Postman、Insomnia，默认脱敏），抓包导出 pcapng / HAR，抓包会话加密保存。
- Map Local / Map Remote，单条重放与编辑后重放；按域名解密列表、“解密此域名”、首次使用检查清单。
- macOS：导入自有根证书、手机连电脑抓包、命令面板与统一快捷键、节点表改为紧凑表格。
- 日志导出为 .log 文件；息屏时降低扩展轮询频率，减少发热耗电。

### 内核

- MITM 主机的 QUIC 自动回落到 TCP，解密不再被 HTTP/3 绕过。
- 内核统一解压 gzip / deflate / br / zstd 正文；流式抓包；WebSocket 消息与 HTTP/2 帧时间线。
- 惰性测速和脚本源码缓存，降低手机发热耗电。
- 短连接关闭后立即释放缓冲，修复大量短连接时内存上涨。

## 还没有在真机上验证的

以下功能已通过 CI 的自动测试，但还没有在真机上完整验证。遇到问题请反馈：

- Linux TUN 模式（不同发行版的 polkit 与路由表）。
- 流量重定向（桌面和安卓）。
- 安卓快捷设置磁贴、始终开启的 VPN、`anixops://` 链接和扫码导入。
