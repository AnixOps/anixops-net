# AnixOps Net v1.0.1

修复 1.0.0 在 iOS 和 macOS 上无法连接的问题，并换上新的 App 图标。Windows、Linux、安卓的 1.0.0 不受那个问题影响，1.0.1 给它们带来新图标和更克制的自动重连。

## 修复

- **iOS / macOS 连接后立即断开（1.0.0）**：1.0.0 的内核与 App 之间的接口版本对不上，连接时隧道报“iOS embedded runtime ABI is
  incompatible”后停止，任何节点都连不上。现在两边一致；构建时也会先检查这一点，不一致的构建不会再发出去。
- **连不上时不再反复重试（iOS、macOS、安卓，以及安卓和 Linux 的 Wi-Fi 规则）**：隧道启动失败时，系统按需连接此前会立刻再次启动，
  每秒重试多次，耗电也刷满日志。现在第一次立即重试，之后间隔 2、4、8、16 秒（Wi-Fi 规则为 30、60、120、240 秒），连续 5 次失败后
  停止自动重连并通知；配置损坏、接口不兼容这类重试也无法解决的失败会立即停止。首页给出“重试”和“换节点”。从 App、小组件、
  快捷指令或控制中心手动连接总是立即执行。连上并保持 1 分钟后计数清零。安卓进程被杀后的自动重启上限从 3 次改为 5 次。

## 变化

- **新的 App 图标（所有平台）**：原来一条弧线连着两个点的图标缩小后像一根棒子，换成一条分出两支、选中的一支走到终点的路线。
  安卓改用自适应图标，并支持 Android 13 的主题图标。
