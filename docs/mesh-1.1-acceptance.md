# 客户端 1.1 组网验收

每次记录客户端和内核的完整提交、构建方式、平台及版本、开关、步骤、实际结果和未执行项。候选验证使用单独构建。发布闸门的打开条件见[统一路线](roadmap.md)，发布手续见[人工介入](manual-intervention.md)。

| 场景 | 自动验证 | 真机验收 |
|---|---|---|
| 旧配置 | 读取旧版明文网络配置，保存后重读，保留入网状态。验证错误或缺少密钥时的回退和关闭闸门后的普通代理启动。 | 保留旧客户端配置副本，升级后分别验证代理连接、已加入的组网、重启和断开后的状态。 |
| 内网域名、重复与地址未受管 | 使用真实快照检查字段是否存在。共享视图样本覆盖显式未受管状态、旧快照省略字段、提示条与入口状态。 | 在可控内网中验证完整域名拷贝和解析，分别验证同网、跨网、缺少来源标记以及地址变化后的提示。 |
| Windows | CI 验证测试机的名称解析规则写入及移除。 | 验证组网与代理可分别开关，系统解析器能访问内网域名。另测组策略管理名称解析的限制。 |
| Linux | CI 构建客户端并验证组网配置与状态投影。 | 验证代理开启时可用的组网路径。只开组网及该模式下的内网域名解析在当前客户端尚不支持。 |
| macOS、iOS、Android | CI 覆盖构建和各平台已有测试。 | 验证系统 VPN 权限、代理与组网开关、真实内网连接、断网后的恢复。iOS 的 TestFlight 与出口合规由维护者验收。 |

记录未受管状态时，以快照中基础节点明确给出的 `addressManaged: false` 为准。旧内核缺少该字段时，客户端仍显示现有地址，且没有未受管提示。共享样本覆盖客户端行为，实际内核是否提供该字段由候选快照和真机验收确认。
