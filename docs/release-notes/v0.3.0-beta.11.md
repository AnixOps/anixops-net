# AnixOps Net v0.3.0-beta.11

这一版的重点是：AnixOps Net 有了自己的 App 图标；按一份第三方静态代码评审报告修了状态保存、系统代理还原和请求列表的一批问题；iOS / macOS 深色模式下的弹出页和禁用按钮更清楚。

## 升级前请先看

- 内核与 beta.10 相同，配置和订阅不需要迁移。
- 安卓 versionCode 升到 3007，可以直接覆盖安装 beta.10。

## 改进

- **新 App 图标（所有平台）**：AnixOps Net 不再和 AnixOps SSH 共用图标，换成自己的产品图标；Windows 窗口内的标志也一起换了。
- **iOS / macOS 深色模式**：弹出页（导入、编辑等）改用抬高一层的底色，不再和后面的窗口混在一起；禁用的按钮改为中性灰，不再是变淡的主题色。
- **macOS 导入页**：宽度固定为 480 pt，高度随当前步骤变化，下方不再留一大块空白。
- **导入**：“从文件导入”不再只写 WireGuard。它本来就能读订阅内容、Clash / Surge / Loon / Quantumult X 配置、节点链接和 WireGuard 配置。
- **文字对比度**：浅色模式下次要文字、强调色和成功 / 警告 / 危险几种文字色略加深，在各种底色上都达到 4.5:1 对比度；iOS / macOS 的时间、大小等说明性小字改用更清楚的次要文字色。
- 节点测速说明里的网址不再显示为可点的链接。
- **安卓**：Wi-Fi 和定位硬件标为可选，没有这些硬件的设备（例如部分平板、电视）也能安装。

## 修复

以下来自一份第三方静态代码评审报告（F01–F15）：

- Linux 系统代理：接管前备份所有会写的设置项，断开时逐项还原，不再留下残余设置。
- 桌面端共享后端：保存状态失败时不再报告成功；新状态写好之前不会先破坏旧状态。
- Windows：刷新订阅不再用旧副本整份覆盖；刷新失败时保留正在编辑的节点；调度和显示用同一份数据。
- iOS / macOS：保存 VPN 配置失败时还原节点密钥；VPN 配置引用自己的那一版节点密钥；刷新期间删除的订阅不会以新 ID 重新出现。
- 安卓：连接超时和建立成功同时发生时，由服务关闭迟到的连接描述符，不再泄漏。
- 流量统计：没有主机名的连接不再把目的 IP 写到磁盘。
- 请求列表（所有平台）：较旧的更新不再覆盖较新的行；桌面端轮询改为串行。
