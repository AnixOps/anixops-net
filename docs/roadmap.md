# 发展路线

客户端 1.1 / 1.2 / 1.3（分别配套内核 0.3.x / 0.4 / 0.5）的功能需求、打开条件与需要维护者处理的事项，统一写在内核仓库的
[发展路线：内核 0.3 → 0.5](https://github.com/AnixOps/networkcore_anixops/blob/main/docs/roadmap-0.5.md)。本仓库不另写副本，避免两份内容不一致。

客户端相关的部分在该文档的：

- 第 3.3 节：客户端 1.1.0（固定内核 `v0.3.1`、打开组网发布闸门、组网界面 1.1 范围）。
- 第 4 节：客户端 1.2（地区、骨干状态、宿主组、外部网络、迁区申请，以及平台对齐项）。
- 第 5 节：客户端 1.3（自定义路径、平台对齐项）。

组网界面的设计与需求见 [mesh-ui.md](mesh-ui.md) 与 [mesh-requirements.md](mesh-requirements.md)，各平台差异见 [platform-parity.md](platform-parity.md)。
客户端 1.1 的自动检查和真机步骤见[组网验收](mesh-1.1-acceptance.md)。
