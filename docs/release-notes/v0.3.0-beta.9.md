# AnixOps Net v0.3.0-beta.9

这一版的重点是：分流规则补齐了与 Surge 的 8 项差距（按 URL 添加 GeoIP / ASN 数据、规则测试、命中次数、更多规则类型），解密域名列表支持通配符和排除，iOS / macOS 抓包能看到没解密的连接；ANX 版每个面板各用一把设备密钥，macOS 默认不再自动检查更新。

## 升级前请先看

- **macOS 自动检查更新默认关闭。** 想继续自动检查，在设置里打开；手动“检查更新”不受影响。
- **ANX 版：每个面板（订阅来源）各用一把设备密钥。** 升级后原来的密钥和授权归最近添加的面板，其他开启设备授权的面板会用新生成的密钥重新授权一次。
- **桌面版（Windows / Linux）概览页在未连接时不再自动测速和测直连延迟**，需要时点“重新测试”。

## 新功能

### 规则与分流

- 规则测试：输入域名或 IP、端口、协议（可选填解析到的 IP），直接显示会命中哪条规则、走哪个出口。
- 规则命中次数：按命中次数排列，`FINAL` 单独一行，可以清零。
- GeoIP / ASN 数据可以按 URL 添加（`geoip-<国家>`、`asn-<号>`，最多 16 份），经代理每天更新，替换同名的内置列表和订阅规则集；内置的仍只有中国的两份列表。
- 规则用到的数据缺失时，规则页会直接提示并可以一键添加，不再静默不匹配。
- “我的规则”新增 `IP-ASN`、`SRC-PORT`、`HOSTNAME-TYPE`、`SUBNET`，`PROTOCOL` 支持 `STUN` / `DOH` / `DOQ`，`FINAL` 支持 `dns-failed`。
- `DEVICE-NAME`：Mac 作网关、桌面局域网共享时，可以按来源 IP 给局域网设备起名并按设备名分流（iOS、安卓上提示不生效）。
- `CELLULAR-RADIO`：iOS 按蜂窝网络制式分流（其他平台提示不生效）。
- `PROCESS-NAME` 在 Windows、Linux 上生效；iOS、macOS、安卓上规则页会提示这类规则不生效。
- 规则集：列表里有网段时，只有域名的连接先按域名匹配，没命中再解析一次；支持 `no-resolve`；内置 Surge 的 `LAN` 规则集。
- 规则集里不支持的规则会显示“已跳过 N 条”及类型；规则页新增“导入时跳过的规则”，列出订阅里没有生效的规则。
- Windows、Linux、安卓的订阅分流会带上订阅的远程规则集，不再因为缺规则集而悄悄退回单节点。

### 解密域名（所有平台）

- 解密域名列表支持通配符（`*`、`?`，与插件 `[MITM] hostname` 写法一致）、排除（`-pattern`，优先于所有解密规则）、单条停用和编辑。
- 隧道运行时会标出解密失败的域名和原因（例如证书固定），可以一键排除。

### 抓包（iOS / macOS）

- 没有解密出请求的连接也会按域名 / 地址列出（连接数、流量、TCP / UDP），点进去可以看原始字节，未在解密列表里的域名可以一键“解密”。
- HTTPS 解密没有真正生效时，请求页会标红并说明原因。
- 断开隧道即停止抓包，进行中的抓包会保存为会话；App 自己重连（换节点、改解密域名等）后自动恢复抓包。

## 隐私

- 新增 `docs/network-behavior.md`，列出客户端自己发出的每一个连接（订阅、测速、出口地址、直连延迟、规则数据、DNS、macOS 更新、崩溃报告）的触发时机、去向和内容；CI 检查打进 App 的地址都在说明里。
