# 组网：客户端需求

状态：需求已确认（2026-11-25），尚未实现。界面细节以 [`mesh-ui.md`](mesh-ui.md) 为准；内核需求见内核仓库 `docs/mesh-requirements.md`。编号沿用项目需求表（R1–R34）。

| 编号 | 需求 |
|---|---|
| R6、R16 | 成员列表按对端展开其通告的全部子网；另有按子网的视图：通告者、当前路径（直连或经几跳中转）、延迟。同一子网被多个对端通告或网段重叠时标出。成员列表保留名称、虚拟地址、直连或中转及跳数、传输方式、延迟。 |
| R9 | 自定义路径的途经节点不可达时，提示具体是哪台节点。 |
| R14 | 未加密网络在界面标注「未加密」。 |
| R17 | 公网网段通告标出；自动发现的局域网网段作为建议列出，确认后才通告。 |
| R20、R24 | 显示节点所属地区；地区变更以申请形式提交，经网络管理者批准后迁移，并提示虚拟地址将变化。 |
| R23 | 组网开关与代理连接开关相互独立；移动端任一开启即建立 VPN，两者共用同一个 VPN。 |
| R25、R26 | 宿主组成员随网关路径，不单独设置自定义路径；网关子网内的设备首版只支持手动命名，不做扫描。 |
| R28 | 成员与网关子网设备显示完整内网域名（`主机名.地区.mesh.internal`）并可复制；重名冲突提示。 |
| R29 | 显示「地址未受管」告警。 |
| R31（部分） | 个人电脑可在客户端中填入入网凭据加入网络。 |

界面不出现任何第三方程序名称；接管对象统称「现有组网程序」。
