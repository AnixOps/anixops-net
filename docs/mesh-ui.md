# 组网界面说明

状态：设计已定，尚未实现。本页是「组网」（内网组网模块）在各平台的界面说明，实现时以本页为准；
要改动先改本页。按钮层级、分组列表、文案语体的条文在 AnixOps Design
（`guidelines/actions.md`、`guidelines/density.md` 第 4 节 N28–N34、`guidelines/voice-and-tone.md`），
客户端的组件对照在 [`ui-ux.md`](ui-ux.md)，这里不重复条文。

## 范围

- 组网只用于内网之间通讯：流量只进入虚拟网段和已接受的通告子网，不作为出口。
- 组网网段优先于代理规则；其余流量不进入组网。
- iOS、Android 只作接入端。macOS、Windows、Linux 是完整节点：可中转、可通告子网、可作宿主。
- 界面不出现任何第三方程序名称。接管对象统称「现有组网程序」。

## 用词

| 中文 | English | 说明 |
|---|---|---|
| 组网 | Mesh | 功能与页面的名称 |
| 网络 | Network | 设备加入的一个组网网络；动作是「加入」 |
| 成员 | Member | 网络里的一台设备；本地这台称「本机」 |
| 地区 | Region | 一组成员，经边界成员与其他地区互联 |
| 子网 | Subnet | 成员通告的局域网网段 |
| 设备 | Device | 子网里手动命名的地址（打印机、NAS 等） |
| 路径 | Path | 到一个成员或子网经过的成员序列 |
| 途经点 | Waypoint | 自定义路径必须经过的成员 |
| 内网域名 | Internal domain name | 成员、虚拟机、设备在组网内的域名 |
| 组地址段 | Group address range | 宿主组的地址段，由网关通告 |
| 骨干 | Backbone | 各地区边界成员之间的链路 |
| 汇总网段 | Summary range | 边界成员通告的其他地区网段 |
| 外部网络 | External network | 其他组网软件的网络，经外部网络桥接节点导入的地址 |

「直连」在组网里指成员之间直接连接，英文写 Peer-to-peer；规则策略的「直连」仍是 Direct，两处用各自的文案键
（见 `ui-ux.md`「界面语言」里一词多义的写法）。

## 层级与角色

层级：网络 → 地区 → 成员 → 子网或虚拟机 → 设备。

| 角色 | 含义 | 展开后显示 |
|---|---|---|
| 边界 | 连接其他地区，每个地区至少两台 | 通告子网（如有） |
| 网关 | 通告所在局域网；无法安装程序的设备经网关到达 | 通告子网、已命名设备 |
| 宿主 | 代表同一物理机上的虚拟机加入，其他成员只见宿主一台 | 虚拟机、通告子网（如有） |
| 主机 | 各自运行程序的服务器或电脑 | 通告子网（如有） |
| 接入端 | 手机；不中转、不通告 | 无 |

两种部署形态混用：服务器各自加入，局域网设备走网关，虚拟机走宿主。每行一个角色标记（N34）。
角色标记不决定能否展开：凡通告子网的成员，不论角色，名称后都写子网数量，行可展开查看其全部通告子网。

### 地区

- 默认四个地区：中国大陆、亚太（日本、香港、台湾等，不拆分）、欧洲、北美。没有边界成员的地区不显示。
- 成员按到各地区边界成员的延迟自动归属，界面显示所属地区和依据（「到 fra-border 延迟最低」）。
- 变更地区走「申请变更」，由网络管理者批准。新增、改名、合并地区只有管理者可做。
- 「申请变更」的入口：桌面在本机页的身份分区；手机在组网页状态分区的「地区」行，点按进入，选择目标地区后提交。
- 申请提交后地区一行显示「待批准」和目标地区，可「撤回申请」；批准前仍按原地区运行。
  批准后地区与虚拟地址更新。被拒绝时显示「已拒绝」和管理者填写的原因（如有），保持原地区，可再次申请。
- 变更地区会更换本机的虚拟地址。申请前的确认写明这一点：「变更地区后虚拟地址改变，使用原地址的连接中断。」
- 地区之间全互联。跨区链路持续测延迟和丢包，变差时自动经第三个地区绕行，恢复后切回。
- 迁区建议：内核重测后发现另一地区持续更近（规范 §15.8 第 5 条）时，地区行与本机页显示「可申请变更至亚太」及两地区的中位延迟，
  操作「申请变更」，目标地区预选为建议的地区。不自动迁移，不发系统通知；申请提交后建议不再显示。
- 「撤回申请」即时生效、可再次申请（T0），不需确认。被拒绝的申请保留「已拒绝」到再次申请或撤回为止；
  手机在地区行第二行显示，桌面在本机页身份分区显示，管理者原因写在其后（「原因：……」），没有原因时不写。
- 申请页（手机）与申请面板（桌面）：目标地区列表只列有边界成员的地区，排除本地区；每项写中位延迟（有测量时）；
  可选填申请理由（不超过 500 字符）；主操作「提交申请」前一行写明「变更地区后虚拟地址改变，使用原地址的连接中断。」
- 申请迁区在手机和桌面都提供（接入端也属于某个地区）。网络尚未加入、地区未定或内核未列出 `mesh_region_requests` 时不显示入口。

### 其他地区

地区之间不传递成员信息（规范 §15.6 第 8 条），本机只看到本地区的成员和边界成员通告的其他地区汇总网段。因此：

- 成员页按地区分组时，其他地区各是一行摘要，不逐台列出成员：地区名、可达状态（可达、已绕行、中断）、当前出口边界成员、
  骨干路径（直连或「经亚太」）、延迟与丢包。展开后列出该地区的汇总网段。快照确实列出其他地区成员时（例如有名字条目），
  才在展开部分逐行列出，连接一列为「跨区 N 跳」。
- 跨区链路中断时，该地区摘要行标「中断」，其汇总网段在子网页标「不可达」，页面顶部一条提示条（见「提示」），不发系统通知。
- 本机是边界成员时（桌面），本机页「运行」分区多一行「骨干」：已连通的骨干链路数 / 总数与状态（正常、部分中断、中断）。

### 外部网络

外部网络是其他组网软件的网络，由同时位于两边的外部网络桥接节点把指定地址单向导入本网络（需求 R36，规范 §15.12）。
界面统一称「外部网络」，不出现任何第三方软件的名称。

- 子网页：外部地址（单个地址或指定子网）作为子网行，带「外部网络」标记，通告者一列写「经 pve-home 桥接」，面板给了名称时
  名称在前、地址在后。单个地址写成不带前缀的地址（`100.101.2.3`），子网照常带前缀。
- 成员页：桥接节点行带「外部网络桥接」标记（与旧网迁移的「桥接」标记区分），展开部分在通告子网之后列出它导入的外部地址。
- 本机自己能直接到达这些地址（同时运行外部组网软件）时，按重叠规则标「与本机网络重叠」，默认使用本机网络。
- 只有面板放行的成员可经桥接访问；未放行时内核不给出可区分的状态，界面不作推断。
- 桥接节点只支持 Linux；客户端内不提供开启桥接的入口。

### 宿主组

- 宿主自动发现本机的虚拟机网桥，机主逐台勾选纳入。
- 虚拟机不作为成员参与路由同步；路径随宿主，不单独设自定义路径。
- 虚拟机的名称在宿主的本机页虚拟机清单里设置，默认取虚拟机的主机名；由宿主向全网发布，其他成员只读。
- 组内虚拟机不是成员（规范 §15.7 第 4 条）。组地址段在子网页是一行，带「宿主组」标记，通告者一列写
  「网关 lon-host 通告的组地址段」，X 为当前通告的网关（备用网关只在主网关离线时通告）；配置了备用网关时详情另列备用网关。
  展开列出组内虚拟机（名称、内网域名、地址）。成员页宿主行展开时，虚拟机在前，组地址段作为子网行在后。
- 组地址段不可达时该行标「不可达」，页面顶部一条提示条（见「提示」）；改用备用网关不提示。

### 子网内的设备

首版只支持手动命名（名称与地址），不做扫描。命名在通告该子网的网关上进行，由网关向全网发布名称，
其他成员据此显示设备名并解析其内网域名。入口是网关行展开部分末尾的「命名设备」和子网详情；
非该网关的成员只读。

### 内网域名

- 每个成员、宿主组里的虚拟机和已命名设备有一个内网域名：`主机名.地区代码.后缀`，例如 `par-host.eu.mesh.internal`；同一地区内可只写主机名。
- 界面以内网域名为主、虚拟地址为辅：成员详情先列域名再列地址，两者都可复制；手机成员行的第二行先写域名的地区部分（`eu.mesh.internal`），地址移到详情；桌面表格保留「虚拟地址」列，排在连接、传输之后。
- 基础节点（边界、网关、宿主、服务器）使用固定虚拟地址；手机和个人电脑默认自动分配，同一设备保持同一地址。网络设置里把服务器地址段和自动分配的地址池分开显示。分配细节以需求文档为准。
- 搜索同时匹配域名。
- 网络设置里有「内网域名」分区：解析开关（即时生效）和后缀（默认 `mesh.internal`，改动需保存）。
- 同一地区内主机名重复时，两行都带「重名」标记，详情里写明与哪台重名；域名解析返回全部同名成员的地址。操作是「重命名」（本机）或无操作（其他成员）。
- 「地址未受管」：成员运行的是现有组网程序、虚拟地址仍由其自动分配时，该行带「地址未受管」标记，
  详情里写明地址可能变化、内网域名可能随之失效。网络内存在此类成员时，组网页顶部另有一条提示条
  （见「提示」），入口状态点同步；不发系统通知。
- 设备先取得虚拟地址再入网。桌面端作为边界、网关、宿主或服务器加入时使用面板或 Agent 下发的固定地址；
  未取得固定地址时不以自动分配代替，加入停在「正在取得虚拟地址」并写明原因。

## 入口与导航

组网的「加入」开关独立于代理的「连接」开关。两者共用同一个 VPN：手机上任一开启即建立 VPN，
关闭其中一个而另一个仍开启时 VPN 保持不断，只撤销对应部分的路由；两个都关闭才断开 VPN。
桌面在代理断开时仍可中转。

首版可保存多个网络。普通节点同时只加入一个；桥接节点例外，可同时加入新旧两个网络，
在网络选择里两个网络都显示「已加入」，并带「桥接」标记。桥接由面板或 Agent 指定，客户端内不提供开启入口。

| 平台 | 入口 | 页内结构 |
|---|---|---|
| iOS、Android | 概览新增「组网」分区（网络、状态、在线数、加入开关），点按进入组网页；不新增底部标签。调试模式无概览，入口在设置首屏 | 状态分区；分段「成员 · 子网 · 路径」；成员详情与路径编辑是下一级页面或面板 |
| macOS、Windows、Linux | 侧栏新增「组网」，位于「代理」之后 | 页面顶部是网络选择、状态条和加入开关；分段「成员 · 子网 · 路径 · 本机」；成员页右侧是详情栏 |

桌面的菜单栏项与托盘菜单显示组网状态和加入开关（S1）。页面的「更多」菜单：网络设置、导入报告（桌面）、
添加网络，分隔线之后是「移除网络」（T1，按名称确认）。

`ui-ux.md` 的入口不变量同样适用于组网页：连接开关仍在原位，组网页不再放第二个连接开关；
加入失败在组网页当页说明原因。

## 页面

### 成员（紧凑档）

- 默认按地区分组：本地区展开，其他地区折叠成一行摘要（台数、跨区路径与延迟、最差状态）。可改为按角色或不分组（N28、N29）。
- 列：成员（状态点、名称、角色标记、所含数量）、虚拟地址、连接、传输、延迟（ms，右对齐）、行尾「更多」。
  按角色或不分组时加「地区」列。
- 连接一列的取值：本机、直连、中转 N 跳、跨区 N 跳、经宿主、经网关、不可达。
- 通告子网的成员（网关、边界、主机、宿主）展开显示其全部通告子网；网关另显示已命名设备；宿主另显示虚拟机，
  虚拟机在前、子网在后。只展开一层，超过五项折叠（N30、N31）。
- 手机每行两行：第一行名称、角色、延迟；第二行内网域名的地区部分 · 连接 · 传输 · 所含数量；虚拟地址在成员详情里。点按展开，展开部分末尾是「成员详情」。
- 筛选：仅在线、不可达、网关、宿主、边界、有自定义路径。排序：名称、延迟、虚拟地址。
- 搜索：名称、内网域名、虚拟地址、子网、设备名；输入子网内的地址可定位其网关（N32）。
- 延迟分级沿用节点表的阈值（120 ms、250 ms），以色点表示，数字不着色；测不通写「超时」。
- 成员详情：状态、虚拟地址与内网域名（均可复制）、地区与归属依据、角色、当前路径（逐跳列出，标明跨区链路）、路径策略、通告子网或虚拟机。

### 子网（紧凑档）

- 列：子网、通告者、地区、当前路径、延迟、状态。
- 标注：多源（同一子网由多个成员通告，展开列出「使用中」与「备用」）、重叠（写明与哪个网段重叠）、
  与本机网络重叠、已拒绝（公网网段，未安装路由）。
- 通告子网与本机局域网重叠时默认使用本机网络并标注，可逐个子网改为走组网。
- 只接受私有地址范围内的通告。

### 路径（宽松档）

三部分，自上而下：

1. 默认选路：分段控件「延迟最低 / 跳数最低」，按网络设置。
2. 跨区链路：每对地区一行，显示当前路径（直连或经某地区绕行）、边界成员、延迟、丢包、状态。
3. 自定义路径：目标（节点或子网）、路径、状态（生效、已回落）。分区操作「添加路径」。

路径编辑（手机是面板，桌面是侧边栏）：目标类型、目标、途经点（可排序）、预览与预计延迟。
按子网指定时写明该子网由谁通告。途经点不支持指定路径时标「仅首跳生效」，并写明其后的路径由该成员决定。
移除路径可撤销（T0）。

### 本机（宽松档，仅桌面）

- 身份：名称、虚拟地址、地区与归属依据、「申请变更」（申请后显示「待批准」或「已拒绝」，见「地区」）。
- 角色：「为其他成员中转」开关、「宿主模式」开关及虚拟机清单。
- 通告子网：已通告的网段；自动发现的本机局域网网段列为建议，逐条「通告」；公网网段写明不可通告。
- 运行：后台服务状态、监听端口、系统 IP 转发状态。

## 状态

| 对象 | 状态 |
|---|---|
| 网络 | 已加入、正在加入、部分不可达、未加入、无法加入 |
| 加密模式 | 前向保密、标准（标记「未启用前向保密」）、未加密（默认拒绝） |
| 路径 | 自动、自定义、已回落、已自动切换、仅首跳生效 |
| 地区 | 自动归属、已固定、本地区、待批准、已拒绝、可申请变更 |
| 其他地区 | 可达、已绕行、中断 |
| 子网类型 | 局域网（不标记）、宿主组、外部网络、汇总 |

每个列表和卡片都有空、加载、错误三种状态（F5）：

- 空：「暂无网络」，主操作「添加网络」；桌面另有次操作「导入配置」。
- 正在加入：状态行按顺序显示进度（正在取得虚拟地址、已连接的对端数、正在测量延迟以确定地区），成员列表用骨架行。
- 部分不可达：页面顶部一条提示条写明哪几台不可达，受影响的行各带一个标记（N33）。
- 错误：写明原因和下一步，只给一个操作（F3）。

### 提示

| 情形 | 文案 | 渠道 |
|---|---|---|
| 自定义路径回落 | 自定义路径已回落：ams-db 不可达。192.168.20.0/24 使用默认路径。 | 组网页提示条、入口状态点，另发一次系统通知 |
| 自定义路径回落：节点不转发（`reason` 为 `unsupported` 或 `not_relay`） | 自定义路径已回落：ams-db 不支持按此路径转发。192.168.20.0/24 使用默认路径。 | 同上；`unsupported` 时该节点可能是目的成员 |

同一网络内所有成员使用同一加密模式。关闭加密的网络默认拒绝：加入、接管导入都拒绝。
允许未加密运行是网络设置里的显式开关，开启前按名称确认（T1）。

加密模式的标记位置固定，「未加密」与「未启用前向保密」相同：组网页状态条的加密模式一项、
网络选择列表里该网络的行、手机概览的「组网」分区、桌面菜单栏项与托盘菜单的状态行。
「未加密」用危险色标记，「未启用前向保密」用警示色标记。

## 添加网络

- 字段：名称、密钥、对端地址（可多个）、虚拟地址、加密模式（默认「前向保密」）。地区自动归属，不在此选择。
- 虚拟地址：手机和个人电脑默认自动分配；桌面端作为基础节点时显示下发的固定地址，只读。
- 桌面另有监听端口。
- 手机支持手动填写、扫描二维码、从文件导入。二维码由桌面端生成，含密钥，生成前确认。
- 主操作「加入」；手机上位于底部，整行宽（P3）。

## 接管与导入报告（仅桌面）

- 启动冲突且本机运行着现有组网程序时，组网页提供「接管并导入」，由后台服务或 Agent 执行。
- 执行前列出将要改动的内容（T3）：停用其系统服务的开机自启并停止进程；导入网络名称、密钥、对端地址、通告子网、
  虚拟地址、监听端口；各平台的系统改动（见下表）。原程序的文件与配置保留，可回滚。
- 导入报告分三组：需确认、已转换、已丢弃，逐项列出原配置与结果。
  本机是基础节点而原配置为自动分配地址时，「已转换」里列出「虚拟地址：自动分配改为固定地址」及新旧地址。「更多」菜单里有「回滚接管」。
- 使用子网映射或远程配置服务器的配置标为「无法自动迁移」，不执行接管。
- 现有网络关闭了加密时默认拒绝接管，确认页写明原因；在网络设置中允许未加密运行后方可接管。

## 系统改动

改动系统的操作在执行前写明会改什么（D3）。

| 平台 | 改动 |
|---|---|
| iOS | 添加 VPN 配置 |
| Android | VPN 授权 |
| macOS | 系统扩展；通告子网时开启系统 IP 转发，需管理员授权 |
| Windows | 后台服务、虚拟网卡、防火墙入站规则；通告子网时开启 IP 转发，需管理员授权 |
| Linux | 后台服务；通告子网时开启系统 IP 转发，需管理员授权 |

## 已定事项

1. 加入开关与连接开关相互独立，共用同一个 VPN。
2. 手机入口在概览的「组网」分区；调试模式在设置首屏。
3. 成员列表默认按地区分组；自定义标签首版不做。
4. 地区自动归属，变更需管理者批准；默认地区为中国大陆、亚太、欧洲、北美。
5. 宿主组的虚拟机随宿主路径，不单独设自定义路径。
6. 子网内的设备首版只手动命名，由网关发布名称。
7. 通告子网与本机局域网重叠时默认使用本机网络。
8. 回落发一次系统通知；跨区自动绕行不发通知。
9. 手机添加网络：手动、扫码、文件导入。
10. 可保存多个网络，普通节点同时只加入一个；桥接节点例外。
11. 桌面客户端提供接管入口；手机不涉及。
12. 组网内的「直连」保留中文，英文为 Peer-to-peer。
13. 其他地区只显示摘要和汇总网段，不逐台列出成员（规范 §15.6 第 8 条）。
14. 迁区申请在手机和桌面都提供；撤回即时生效。
15. 外部网络只显示面板标注过的地址，标「外部网络」，不出现第三方软件名称。
