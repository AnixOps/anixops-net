# AnixOps Net v0.3.0-beta.10

这一版的重点是：所有平台都能对单个节点做“节点体检”，看握手和请求延迟、抖动、丢包，可选测下载速度和下载时的延迟；界面和文档统一改用中性用词。

## 升级前请先看

- **节点体检只在你点开始时运行。** “测下载速度”默认关闭；勾选后会经节点下载最多 200 MB，按流量计费的节点请只测延迟。
- 用户协议更新到 2.1.2，只是措辞调整，不需要重新同意。

## 新功能

### 节点体检（所有平台）

- 入口：iOS、macOS、安卓在节点的菜单里，Windows、Linux 在节点详情里。
- 经这个节点做几轮建连和 TLS 握手、请求延迟，给出中位数、抖动和丢包。
- 勾选“测下载速度”时，另外测下载速度（每秒曲线和峰值）以及下载时的请求延迟；到 200 MB 即停。
- iOS、macOS 在 App 里直接经节点测，不经过隧道，未连接时也能测。
- 每个连接去哪、带什么，见 `docs/network-behavior.md` 的“节点体检”。

## 改进

- 界面、下载页、发布说明和文档改用中性用词（例如“服务商”）；CI 检查新增内容不再出现这些词。
- iOS 规则页空状态去掉了过时的“内置预设”说明。

## 修复

- Linux 原生窗口的截图测试在冷启动时偶尔拿不到窗口尺寸：截图前先等窗口有了尺寸。
