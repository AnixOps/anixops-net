# 手机连电脑抓包

网络调试客户端计划 D4：手机把 Wi-Fi 代理指向电脑，在电脑上看手机的请求（开了 HTTPS 解密时也能看到解密后的内容）。

## 用法

1. 电脑上的 AnixOps Net 先连接。
2. 打开「扩展」页的「手机抓包」开关，默认端口是 8899。
3. 手机和电脑连同一个 Wi-Fi，用手机相机扫页面上的二维码，打开设置页 `http://<电脑地址>:<端口>/`。
4. 按设置页的步骤操作：
   - 在手机的 Wi-Fi 设置里把代理设为手动，填电脑地址和端口；
   - 安装根证书：iPhone 用描述文件 `/ca.mobileconfig`，装好后还要在“证书信任设置”里打开信任；Android 用 `/ca.crt`。
5. 在手机上打开 `http://cert.anixops/`，页面显示“代理已生效”就说明设置成功。手机的连接会出现在活动页（macOS 上是请求页），进程名显示为 `LAN <手机地址>`。

## 安全边界

- 只接受回环、私有网段（RFC 1918、100.64/10）、链路本地和 IPv6 ULA 地址的连接，公网来源会被直接关闭。
- 设置页只提供根证书，不提供私钥。证书页和桌面都会显示 SHA-256 指纹，两边一致才安装。
- 断开连接或退出客户端时，共享也随之关闭。

## 根证书

默认每台电脑生成自己的根证书（计划 F2）。Windows 和 Linux 可以在「扩展」页的「自己的根证书」里换成团队已有的 CA，需要 PEM 格式的证书和 PKCS#8 私钥（`BEGIN PRIVATE KEY`）。换完后，手机和其他设备上的根证书都要重新安装。macOS 暂时还不能导入自有 CA，仍使用钥匙串里生成的根证书。

内核接口见 networkcore 的 `crates/engine-embedded/src/lan_share.rs`，包括控制命令 `lan_share`、`start_lan_share` 和 `stop_lan_share`。
