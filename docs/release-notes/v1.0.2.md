# AnixOps Net v1.0.2

所有平台的稳定性与安全加固：修复 Shadowsocks / Snell 大流量时卡住、Windows 开启 HTTPS 解密报错，桌面与安卓加上全局模式，设置页更精简。

## 新功能

- **全局模式（Windows、Linux、安卓）**：分流模式除了规则、直连，现在也可以选“全局”，所有流量走所选策略组或节点。
  此前只有 iOS 和 macOS 有。首页和规则页都能切换，`anixops://mode?set=global` 链接同样可用。

## 修复

- **Shadowsocks / Snell 大流量时连接卡住（所有平台）**：Shadowsocks 2022、Shadowsocks AEAD 与 Snell 出站在发送缓冲已满、
  服务端又先回数据时，读写会互相等待，连接停住直到超时，大文件上传或下载时容易遇到（Windows 上最明显）。现在读不再等待排队中的写。
- **Windows 开启 HTTPS 解密报错**：开启时提示 “enabled native HTTPS MITM requires service-owned system proxy lifecycle”。
  现在由窗口持有系统代理时也能开启解密，配置文件的读写重新经过内核的受信文件检查。
- **安全加固**：内核本地管理接口先校验请求头和鉴权再读取请求体，并限制连接数和请求体大小；入站连接的生命周期与文件描述符预算
  更严格。数据包解析库 etherparse 升到 0.16.1（修复 RUSTSEC-2026-0596 中 IPv6 扩展头的越界读）。
- **桌面本地通信**：客户端与后台服务之间的消息改为一次写出，一端关闭时另一端不再收到半条消息。

## 变化

- **设置页更精简（所有平台）**：首屏只留常用项，通知、隐私与诊断、高级收进二级页面；HTTPS 解密开关移到证书旁单独成区；
  插件、脚本、映射等列表超过 5 条时折叠，可展开查看全部。
