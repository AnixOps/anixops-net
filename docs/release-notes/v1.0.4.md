# AnixOps Net v1.0.4

安全修复版本：处理 2026-11-25 安全审计中与客户端相关的问题。

## 安全修复

- **抓包正文临时文件（Windows、Linux、macOS 桌面端）**：用其他应用打开的请求或响应正文，改写到只有当前账号可以访问的目录，
  文件以仅本人可读写的权限创建；旧的共享目录在启动时删除（审计 NET-01）。
- **订阅下载大小上限（所有平台）**：单个订阅下载超过 16 MiB 时停止并报错，防止异常订阅耗尽内存（审计 NET-02）。
- **内核管理接口（内核 1ebef29）**：管理接口默认只监听回环地址，空令牌拒绝启动（审计 CORE-01）。

## 其他

- macOS：新增 MCP 只读接口（设置 > 高级 > 外部工具访问，默认关闭；开启后本机 AI 工具可读取脱敏后的状态与请求记录），见 `docs/mcp-desktop.md`。
- 内核由 8a06911 升至 1ebef29，其余变化为抓包导出的脱敏参数；连接、分流与解密行为没有变化。
- 组网（内网组网）功能不在本版本中，相关界面不显示。
